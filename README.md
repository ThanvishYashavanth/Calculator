
# Calculator

A modern and responsive scientific calculator built using HTML5, CSS3, and Vanilla JavaScript.

## About the Project

Nova Calculator is a web-based scientific calculator designed to provide a smooth and user-friendly calculation experience. It features a modern interface, responsive layout, scientific functions, and keyboard support.

This project demonstrates frontend development skills, JavaScript logic, DOM manipulation, and responsive web design.

## Features

- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Scientific calculations
- Trigonometric functions (sin, cos, tan)
- Square root calculations
- Logarithmic functions (log and ln)
- Exponent and power calculations
- Factorial calculations
- Percentage calculations
- Degree and Radian modes
- Previous answer (Ans) support
- Recent calculation history
- Keyboard input support
- Responsive design for desktop and mobile devices
- Custom expression parser without using `eval()`

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Edge, Firefox, etc.)
- Visual Studio Code (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/nova-calculator.git
   ```

2. Open the project folder:

   ```bash
   cd nova-calculator
   ```

3. Open `index.html` in your browser.

No additional packages or installations are required.

## Keyboard Shortcuts

| Keyboard Key | Action |
|---|---|
| 0–9 | Enter numbers |
| +, -, *, / | Arithmetic operations |
| Enter | Calculate result |
| Backspace | Delete last character |
| Escape | Clear calculator |
